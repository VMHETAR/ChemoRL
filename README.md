This is an experimentation project of the research titled - "Learning Personalized Chemotherapy Dosing Policies for Lung Cancer Using Vision-Based Reinforcement Learning with Generative Disease Progression Modeling"

Research Objective:

To develop and evaluate a vision-based reinforcement learning framework that learns personalized chemotherapy dosing policies for lung cancer patients by analyzing CT images and relevant clinical variables, while interacting with a generative disease progression simulator that models treatment response and toxicity over multiple chemotherapy cycles.

Scope of the Project:

The project WILL include

1. Lung cancer CT image analysis

2. Vision encoder (CNN/ViT)

3. Reinforcement Learning

4. Chemotherapy dose optimization

5. RECIST 1.1 response evaluation

6. CTCAE toxicity assessment

7. Disease progression simulator

8. Generative visualization/modeling of disease progression

9. Comparison with conventional dosing strategies
